## Table III: 실내 등가 링크 전력 예산

거리 620 km, 파장 1550 nm, 맑음, 천정각 0°, 지향 오차 20 µrad, 수신 개구 직경 31.8 cm 조건에서 Friis 식과 가우시안 빔 모델로 독립 계산한 v29 결과다. 논문과 같이 이득은 양수, 손실은 음수로 나타냈으며, 순이득은 각 항목을 합산했다. 실내 EDFA 이득 20 dB는 논문값을 그대로 사용했으며, **독립적으로 추정하거나 28 GBaud 시뮬레이션에 적용하지 않았다.**

| 항목 | 논문 (dB) | v29 독립 계산 (dB) |
| --- | ---: | ---: |
| 송신 망원경 이득 | +109.15 | +109.146663 |
| 지향 손실 | −35.68 | −35.679737 |
| 자유공간 손실 | −254.03 | −254.025397 |
| 대기 손실 | −3.00 | −2.940000 |

| 실내 EDFA 적용 후 순이득 (계산값) | −47.38 | −47.313565 |

EDFA 적용 전 전력 예산의 절대 차이는 **0.066435 dB**다. 이 중 0.060 dB는 대기 손실 항목의 차이에서 나온다(독립 계산 `0.147 × 20 = 2.94` dB, 논문 표 3 dB). 대신 식 (5)–(12) 전체를 사용해 빔 확산을 독립 계산하면 EDFA 적용 전 손실은 **67.312209 dB**다. 이는 평균 전파 손실의 산술 검산이며, 확률적 페이딩·DSP·하드웨어 실험을 검증한 결과는 아니다.
